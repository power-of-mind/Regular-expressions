# 🔍 Regular Expressions

Учебный проект по изучению регулярных выражений (Regular Expressions) в Python.

Проект демонстрирует использование модуля `re` для поиска, проверки, извлечения и замены данных в текстовых строках.

---

## 📋 Описание

Регулярные выражения (Regex) — это мощный инструмент для работы с текстом, позволяющий находить шаблоны в строках, проверять корректность данных и выполнять сложную обработку текстовой информации.

В рамках проекта рассматриваются:

* поиск текста по шаблону;
* проверка формата данных;
* извлечение информации из строк;
* замена текста;
* работа с группами захвата;
* использование специальных символов и квантификаторов.

---

## 🎯 Цели проекта

* Изучить синтаксис регулярных выражений.

# 🔎 Основные операции

## Поиск совпадения

```python
import re

text = "Python 3.12"

result = re.search(r"\d+\.\d+", text)

print(result.group())
```

Результат:

```text
3.12
```

---

## Поиск всех совпадений

```python
import re

text = "Телефоны: 12345 и 67890"

numbers = re.findall(r"\d+", text)

print(numbers)
```

Результат:

```text
['12345', '67890']
```

---

## Замена текста

```python
import re

text = "Hello World"

result = re.sub(r"World", "Python", text)

print(result)
```

Результат:

```text
Hello Python
```

---

## Проверка строки

```python
import re

email = "user@example.com"

pattern = r"^[\w\.-]+@[\w\.-]+\.\w+$"

print(bool(re.match(pattern, email)))
```

Результат:

```text
True
```

# 📚 Основные метасимволы

| Символ | Значение             |
| ------ | -------------------- |
| `.`    | Любой символ         |
| `\d`   | Цифра                |
| `\D`   | Не цифра             |
| `\w`   | Буква, цифра или `_` |
| `\W`   | Не буква             |
| `\s`   | Пробельный символ    |
| `\S`   | Не пробельный символ |
| `^`    | Начало строки        |
| `$`    | Конец строки         |

---

# 🔢 Квантификаторы

| Выражение | Значение      |
| --------- | ------------- |
| `*`       | 0 и более     |
| `+`       | 1 и более     |
| `?`       | 0 или 1       |
| `{n}`     | Ровно n раз   |
| `{n,m}`   | От n до m раз |

Пример:

```python
import re

text = "aaa"

print(bool(re.fullmatch(r"a{3}", text)))
```

---

# 🎯 Группы захвата

```python
import re

text = "Дата: 12-05-2025"

match = re.search(
    r"(\d{2})-(\d{2})-(\d{4})",
    text
)

print(match.groups())
```

Результат:

```text
('12', '05', '2025')
```

# 📧 Проверка email

```python
import re

pattern = r"^[\w\.-]+@[\w\.-]+\.\w+$"

email = "user@example.com"

if re.match(pattern, email):
    print("Email корректен")
```

# 📞 Проверка номера телефона

```python
import re

phone = "+7 (999) 123-45-67"

pattern = r"\+7\s?\(\d{3}\)\s?\d{3}-\d{2}-\d{2}"

print(bool(re.fullmatch(pattern, phone)))
```
